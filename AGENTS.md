# FusionStructure Landing

## Alcance
Este repositorio es exclusivamente la landing pública del ecosistema FusionStructure.

## Reglas
- No introducir motores de cálculo, solver 2D/3D, CAD, BIM o lógica de producto.
- No introducir el brandbook completo; sólo assets de marca necesarios para la landing.
- Las herramientas externas se enlazan mediante `src/foundation/productLinks.ts`.
- Mantener la landing responsive, accesible y ligera.
- Antes de fusionar cambios ejecutar `npm run check`.
